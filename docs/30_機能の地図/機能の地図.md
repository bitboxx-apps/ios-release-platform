# 機能の地図

機能ごとに、仕様（OpenSpec の change / spec）とコードの場所を対応させる表。機能を足したら、ここにも 1 行足す（`AGENTS.md` の完了前のチェックリスト）。

- アーカイブ済みの仕様は `openspec/specs/<capability>/spec.md`、進行中の仕様は `openspec/changes/<change-id>/` にある。
- リンクは Vault の根からのパスで書く（例: `[[openspec/changes/<change-id>/proposal|<change-id>]]`）。`proposal` や `spec` は名前が重なるため。

| 機能 | 仕様 | コード |
|---|---|---|
| リポジトリの構成・依存方向 | [[openspec/specs/repo-layout/spec\|repo-layout]] | `apps/`、`release/`、`.github/workflows/` |
| ドキュメントの構成（この Vault） | [[openspec/changes/restructure-docs-layout/proposal\|restructure-docs-layout]] | `docs/` |
| iOS のリリース基盤（bootstrap / 署名 / CI / 配布） | 〈`ios-release` の spec はまだない〉 | `release/ios/`、`.github/workflows/ios-*.yml` |
