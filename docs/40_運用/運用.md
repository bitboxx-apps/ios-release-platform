## よく使うコマンド
```bash
./release/ios/bootstrap/doctor.sh            # 前提ツールの確認（何もインストールしない）
./release/ios/bootstrap/bootstrap.sh         # 検証のみ（何も変更しない）
./release/ios/scripts/create_project.sh      # Xcode プロジェクトの生成（すでにあればスキップ）
./release/ios/scripts/deploy.sh [beta|release|test]  # ローカルで CI と同じ fastlane を実行（人間の指示があるときだけ）
openspec list                                # 進行中の change
openspec validate <change-id> --strict       # change の検証
```

## してはいけないこと
`AGENTS.md` §2.6。特に `bootstrap.sh --init`、`setup_secrets.sh`、`gh secret set`、`fastlane match`（readonly 以外）、TestFlight / App Store への配布は、人間の指示なしに実行しない。
