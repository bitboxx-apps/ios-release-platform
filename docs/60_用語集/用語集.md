# 用語集

足すときは [[用語のひな形]] の 1 行を使う。

| 用語 | 英語・コード上の名前 | 意味 | 関連 |
|---|---|---|---|
| bootstrap | `release/ios/bootstrap/bootstrap.sh` | `.env` から Xcode プロジェクト・fastlane の設定・証明書・Secrets を用意する手順。`--init` なしは検証だけ | [[全体像]] |
| 環境変数の層 | `.env.platform` / `.env.app` / `.env.local` | 組織の秘密・アプリの識別情報・開発者の上書き。上の層が下を上書きする | [[全体像]] |
| match | fastlane match | 証明書と Provisioning Profile を git で共有する仕組み。readonly 以外は人間の指示なしに実行しない | [[運用]] |
| change | OpenSpec change / `openspec/changes/<change-id>/` | 仕様の変更提案。proposal / tasks / design / spec delta からなる | [[機能の地図]] |
| capability | `openspec/specs/<capability>/` | 仕様のまとまり（例: `repo-layout`、`ios-app`） | [[機能の地図]] |
| spec delta | `## ADDED Requirements` など | change の中の、仕様の差分。アーカイブすると `openspec/specs/` に取り込まれる | [[機能の地図]] |
| Vault | Obsidian vault | Obsidian で開くフォルダー。このリポジトリでは `docs/` | [[ホーム]] |
