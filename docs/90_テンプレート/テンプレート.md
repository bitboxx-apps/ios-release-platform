# テンプレート

新しいノートは、ここのひな形をコピーして作る（Obsidian のコアプラグイン「テンプレート」を有効にすると、コマンドパレットの「テンプレートを挿入」で入れられる。フォルダーは `.obsidian/templates.json` で設定済み）。

| ひな形 | 使うとき | 置き場所 |
|---|---|---|
| [[事故と教訓のひな形]] | 再発しそうな問題が起きて、原因が分かったとき | `50_事故と教訓/YYYY-MM-DD_<短い題>.md` |
| [[ドキュメントのひな形]] | 全体像・ドメイン知識・運用のノートを足すとき | 該当するフォルダー |
| [[用語のひな形]] | 用語集に足すとき | [[用語集]] に追記 |

仕様（proposal / tasks / design / spec delta）は、ここではなく OpenSpec の書き方に従う（`AGENTS.md` §3）。
